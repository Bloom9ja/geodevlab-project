# SchoolReach: Primary School Accessibility in Odeda LGA

Which settlements in Odeda LGA, Ogun State have inadequate road-based access to primary schools?

Will be built over twelve months as part of GeoDev Lab Africa. See [project-brief.md](./project-brief.md) for the full brief — the question, why it matters, the data required, where each dataset comes from, and what the finished system would look like.

**Status:** Week 1 — data feasibility and Area of Interest check in progress.

## Data Sources (summary)

| Dataset | Provider |
|---|---|
| Odeda LGA boundary | HDX COD-AB Nigeria |
| Settlements | GRID3 (Ogun State extract) |
| Primary schools | GRID3 Nigeria Schools |
| Road network | OpenStreetMap (HOTOSM export) |
| Population (age-structured) | WorldPop |

Full provenance (versions, download dates, licenses) will be recorded in `docs/data-sources.md` as each dataset is acquired.
